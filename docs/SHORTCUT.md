# ショートカットで壁紙にする

夜じたてで焼いた一枚を、**額装したままの姿で**壁紙に入れる手順です。
2026-08-31 にオーナーの実機（iPhone・docomo）で**通ることを確認済み**。

## いちばん大事なこと

iOSが壁紙を勝手に拡大するのは、**「被写体を切り取る」という設定が既定でオンだから**です。
ショートカットの「壁紙に写真を設定」には**この設定を切るスイッチがあります。**

**ここを切れば、額装した通りに入ります。**指2本で縮める操作は要りません。

> 当初は「ショートカットは編集画面を通らないから拡大されない」と考えていました。**これは外れです。**
> ショートカット側にも同じ仕掛けが載っていて、違うのは**切れること**でした。

---

## 甲 — 保存した一枚を壁紙にする

### 準備

夜じたて（https://hirohgxx.github.io/yo-jitate/ ）で一枚を「写真に保存」しておきます。

### ショートカットを作る

「ショートカット」アプリ → 右上の **＋** → 下の検索欄から2つ足します。

**1つめ**: 検索欄に `最新の写真` → **「最近の写真を取得」**

- 行は「最近 **1枚の写真** を取得」になります（1枚のままでOK）
- 行の **∨** を開いて、**「スクリーンショットを含める」を必ずオフ**にする
  → **既定はオンです。**オンのままだと、直前に撮ったスクリーンショットが壁紙になります（実際になりました）

**2つめ**: 検索欄に `壁紙` → **「壁紙に写真を設定」**

- 「壁紙を切り替える」「すべての壁紙を取得」も出てきますが、**別物です。**
  選ぶのは説明が「壁紙を指定した画像に設定します」のもの
- 行は「壁紙◯◯ を **ロック画面、ホーム画面** の **最新の写真** に設定」になります
  （前のアクションの写真が自動でつながります）
- 行の **∨** を開いて:

| 設定 | 既定 | どうするか |
|---|---|---|
| プレビューを表示 | オフ | **オフのまま** |
| **被写体を切り取る** | **オン** | **オフにする** ← これが拡大の正体 |
| 背景のぼかし | オフ | **オフのまま** |

右上の**「完了」**で保存 → タップして実行。初回は写真へのアクセスを聞かれるので許可します。

### 出来上がり

ロック画面・ホーム画面の両方に、**額装した通りの姿**で入ります。
上に藍色の帯が出て、時計が顔にも髪にも掛かりません。

## 乙 — 毎朝ひとりでに替える

夜じたては**毎朝ひとつだけ、額装済みの一枚を固定URLに置いています。**
日付から一意に決まるので、**同じ日なら誰の端末でも同じ一枚**です（乱数を使っていません）。
33柱 × 10段を **410日で一巡**し、御霊も深さも毎日変わります（新しく来たトバリ・ゴコウ・マミ・サスラは多めに巡ってきます）。

### 取りにくる先

自分の端末に合うURLは、https://hirohgxx.github.io/yo-jitate/#daily （URL の後ろに `#daily`）で開くと ≡ の札に出ます。コピー釦つきです。

| 端末 | URL |
|---|---|
| iPhone 14 Pro / 15 / 16 | `https://github.com/hiroHGxx/yo-jitate/releases/download/daily/yo-jitate-1179x2556.jpg` |
| iPhone 14 Pro Max / 15・16 Plus / Pro Max | `https://github.com/hiroHGxx/yo-jitate/releases/download/daily/yo-jitate-1290x2796.jpg` |
| iPhone 12 / 13 / 14 | `https://github.com/hiroHGxx/yo-jitate/releases/download/daily/yo-jitate-1170x2532.jpg` |

寸法が合わないと、**iOSが差を埋めようとします。**
自分の端末の実寸は、夜じたての画面の **▸ この端末で通ったこと** に出ています（例: `1179 × 2556`）。

### ショートカットを作る

甲を**複製**して（一覧で長押し → 複製）、1つめを差し替えるのが早いです。
2つめの設定（被写体を切り取るオフ）がそのまま残ります。

1. 1つめの「最近の写真を取得」を **✕** で消す
2. **「URLの内容を取得」** を足す。**足すと下に付くので、長押しして上へ動かす**
3. URL欄に貼る。**夜じたての画面の「URLをコピー」を使ってください**——
   端末の寸法に合うURLが入っています。手で打つと `releases` の `s` を落とします（実際に落ちました）
4. 2つめの入力が**赤い「最新の写真」のままなら押して「URLの内容」に変える**。
   消した1つめを指したまま迷子になっている印です。直ると青くなります
5. 「方法」は **GET** のまま。「ヘッダ」は触りません

> **初回の実行で「〈名前〉が "github.com" に接続することを許可しますか？」と聞かれます。「許可」を押してください。**
> 2回目からは聞かれません。**オートメーションに載せる前に、一度手で実行して許可を済ませておくこと。**

> `application/octet-stream` で返るので「イメージを変換」が要るかと構えていましたが、
> **要りませんでした**（2026-08-31 実機で確認）。断られたときだけ挟んでください。

### 名前を分かりやすくしておく

上の題名の部分を押して、**「夜じたて・今日の一枚」**などに変えておきます。
次のオートメーションで**一覧から選ぶとき**に、既定の名前（「コレクションを開く 1」など）だと分かりません。

### 毎朝ひとりでに動かす ← ここまでやらないと画面は変わりません

**固定URLの中身が替わっても、それだけでは端末の壁紙は変わりません。**
ショートカットが走ったときに初めて替わります。だから時刻の仕掛けが要ります。

1. ショートカットアプリの下にある **オートメーション** を開く
2. 右上の **＋**
3. **「時刻」** を選ぶ
4. 時刻を **朝6時以降**にする（焼き上がるのが日本時間の朝5時ごろ）／繰り返しは **毎日**
5. **「実行前に尋ねる」をオフ**にする（オンだと毎朝通知を押すことになります）。
   「確認なしで実行しますか？」と出たら **「尋ねない」**
6. 実行するものに、さっき名前を変えたショートカットを選ぶ

**最初の一度だけ**: 初めて走ったあと、ロック画面を長押しして、いま替わった絵の枠が選ばれているか見てください。
ショートカットは決まった枠の中身を書き換えるだけで、その枠を表に出すことまではしません。
別の壁紙を手で選んだあとは、この枠を選び直すまで画面は替わりません（中身は毎朝替わり続けています）。

## うまくいかないときに見るところ

| 起きたこと | 見るところ |
|---|---|
| **拡大されて入る** | **「被写体を切り取る」がオンのまま**。ここを切る |
| **関係ない絵が入る** | 「スクリーンショットを含める」がオン。または、夜じたてで保存したあとに別の写真を撮っている |
| 「イメージが必要です」と断られる（乙） | 1と2のあいだに **「イメージを変換」** を足す（通常は不要） |
| URLを入れたのに404になる | `releases` の **s** が落ちていないか。画面の「URLをコピー」を使う |
| 2行目の入力が**赤い** | 消したアクションを指したまま。押して「URLの内容」に選び直す |
| **GitHubに繋がらない** | 初回の接続許可を押していない。一度**手で実行**して「許可」を押す |
| **URLの中身は替わったのに壁紙が古いまま** | ショートカットが走っていない。**オートメーションを作る**（下の「毎朝ひとりでに動かす」） |
| **URLの中身は替わったのに壁紙が古いまま（オートメーションは作ってある）** | **2026-09-04 実機で特定**: 「壁紙に写真を設定」は、既存のロック画面の**同じ枠**（Shortcuts上の名前は「壁紙◯◯」）の中身を書き換えるだけで、**その枠を自動でアクティブにはしない**。あとから別の壁紙を手で選んでいると、中身は正しく更新され続けていても画面には出ない。**ロック画面を長押し → その枠（`壁紙◯◯`の絵）まで戻ってタップして選ぶ**。一度選べば、以後は同じ枠が上書きされ続けるので選び直しは不要（2026-09-04 実機でテスト用の絵に差し替えて確認済み）。 |
| 昨日と同じ絵のまま（乙） | 焼く側がその日まだ走っていない可能性。[Actions の履歴](https://github.com/hiroHGxx/yo-jitate/actions)を見る。ショートカットを手で1回押せば追いつく |
| ロック画面だけ替わる | 「壁紙に写真を設定」で**ロック画面・ホーム画面の両方**が選ばれているか |
| オートメーションが動かない | 「実行前に尋ねる」がオンのまま |

## 配っているものについて

固定URLに置いてあるのは、**額装した一枚**です。公式の札絵の原本ではありません。
原本は素材蔵（`kura.vibe.co.jp`）にあり、**このリポジトリには1枚も置いていません**。
毎朝、素材蔵から読み、額装して、書き出しています。

本作は『月蝕綺譚 -Luna Occulta-』の**二次創作**であり、**公式とは関係ありません**。
